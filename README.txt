MTZ LINK IN BIO - HOW TO PUBLISH

FILES
index.html  the page (do not need to edit)
links.js    YOUR LINKS - the only file you edit
logo.png    your original logo, unmodified

EDIT LINKS
Open links.js in any text editor. Paste your real profile URL between the quotes
of each url:"" (must start with https://). Copy a line to add a link, delete a line
to remove one. Empty links show "SOON" and never open a fake page.

PUBLISH FREE (Netlify, about 2 minutes)
1. Go to app.netlify.com/drop and create a free account.
2. Drag the whole mtz-site FOLDER onto the page.
3. You get a public URL like https://something.netlify.app. Done.
   (To update later: open your site > Deploys > drag the folder again.)

ALTERNATIVE: Cloudflare Pages > Create > Upload assets > upload the folder.
ALTERNATIVE: GitHub Pages - put these files in a repo, Settings > Pages.

CUSTOM DOMAIN
1. Buy a domain (e.g. mtz.com / mtzwear.com) at any registrar.
2. Netlify: Site configuration > Domain management > Add a domain.
3. Follow the DNS instructions shown there (at your registrar, add the records
   Netlify lists). HTTPS certificate is issued automatically, usually within minutes.
